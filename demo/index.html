Kernel model

A kernel model measures similarity while preserving non-linear structure.

z=\sum_i \alpha_i K(x,x_i)z = Σ αᵢK(x,xᵢ)

Use rbf when the relationship is smooth:

from sklearn.svm import SVC
model = SVC(kernel="rbf")
